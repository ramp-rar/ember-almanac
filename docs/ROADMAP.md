# Roadmap — матрица Эйзенхауэра (для full-stack части)

## 1. Срочно и важно — делать сейчас (Phase 1)
- Контракт данных с командой (схема, meta.json) + мок-фикстуры, чтобы не ждать их
- Скелет репо, CI, Vercel + Neon + Blob, /api/health
- HonestValue + statusOf + ratioToMedian + тренд (чистые функции, тесты первыми)
- F02 Календарь (главный экран) · F01 выбор AOI (страна → координаты → рисование)
- F03 сравнение с медианой · F04 годовой ряд + тренд + аномалии
- F05 выгрузка CSV (summary → detections) · F06 честные пометки
- F07 бюджеты производительности и e2e

## 2. Важно, но не срочно — запланировать (Phase 2)
- Raw ↔ Harmonized слайдер (главный wow для жюри)
- Sensor Lab (почему сенсоры расходятся) · Observation coverage по swath outlines
- Fire Stripes / share card · мини-игра «Sensor or reality?»
- RU-локализация · полный a11y-аудит · мониторинг ошибок

## 3. Срочно, но не важно — автоматизировать / делегировать агентам
- Генерация фикстур, линтинг, changelog, скриншоты для страницы проекта (qa-engineer + CI)
- Live 24h NRT-слой (полезен для демо, но не ядро)
- Оформление README и записи демо-видео

## 4. Не срочно и не важно — исключить
AI-чатбот · 3D-глобус · логин/профили · лидерборды/стрики/уведомления · «прогноз пожаров» ·
отдельный FastAPI/PostGIS · сонификация (вернуться только после Phase 2)
